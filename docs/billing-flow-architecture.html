Phase 9 · Refund (Block Time only)
💸 Refund request
Pilot requests refund on unused Block Time hours.

System recalculates: hours already flown × $330/hr (standard rate).
Refund = amount originally paid − recalculated amount at $330.

Example: Bought 50h @ $300/hr = $15,000. Flew 20h. Recalc: 20h × $330 = $6,600. Refund = $15,000 − $6,600 = $8,400.
↓
🔧 Admin approves & processes refund
Admin reviews request, confirms calculation, issues Stripe refund or manual bank transfer. Package status → refunded.

🔧 Billing flags & alerts
